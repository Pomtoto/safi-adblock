حاجب نطاقات إعلانات وتتبّع للأندرويد **بدون روت**. تطبيق أصلي بواجهة عربية، وليس صفحة ويب أو تعديلًا على التطبيقات الأخرى.

> النسخة الحالية 1.2.0 تجريبية. لا يستطيع حاجب DNS إزالة كل الإعلانات. اقرأ حدود العمل أدناه قبل التثبيت.

## جديد في 1.2.0

- **إنترنت أكثر ثباتًا عند تعطّل مزوّد DNS**: دمج الاستعلامات المتطابقة، قاطع دائرة لكل خادم، ميزانية زمنية للاستعلام الواحد، وذاكرة فشل قصيرة. الهدف: لا يتجمد التصفح لثوانٍ طويلة إذا صار المزوّد بطيئًا أو محجوبًا.
- **اختيار مزوّد DNS المشفّر**: Cloudflare (الافتراضي)، AdGuard DNS، وGoogle Public DNS. كلها مُختبرة فعليًا عبر اتصال TLS حقيقي من كود التطبيق نفسه (بدون اسم مضيف يحتاج حلًّا مسبقًا).
- **قائمة إضافية اختيارية من رابط https**: قائمة نطاقات، أو صيغة hosts، أو `||domain^`. تُدمج مع القائمة المحلية، وفشل التنزيل يبقي القائمة السابقة.
- **قراءة قوائم أكثر تسامحًا**: الأسطر غير الصالحة تُتجاهل ويُعرض عددها، بدل أن يُلغى ملف القائمة كاملًا. وأي قائمة ناقصة أو تالفة تُرفض ولا تستبدل السليمة.
- **زر الاختصارات السريعة** لتشغيل/إيقاف الحماية بضغطة، ودعم **«VPN دائم التشغيل»** مع تحذير صريح من خيار «حظر الاتصالات بدون VPN».
- **شفافية أعلى**: مزوّد DNS الحالي، زمن آخر رد، بصمة ملف القائمة، عدد الطلبات المدمجة، وتنبيه إذا كان خيار الحظر بدون VPN مفعّلًا.
- **سجل أعطال محلي**: آخر الأخطاء على جهازك فقط، بلا إرسال، للمساعدة في التشخيص.

## التشغيل

1. انسخ `Safi-1.2.0-github.apk` إلى هاتف أندرويد 8.0 أو أحدث وثبّته. إذا طُلب ذلك، اسمح بالتثبيت من المتصفح أو مدير الملفات الذي فتحته فقط. لا يحتاج التطبيق تعطيل Play Protect أو تثبيت شهادة.
2. افتح **صافي** واضغط **تشغيل الحماية**.
3. اقرأ توضيح الخصوصية ووافق على طلب اتصال VPN من أندرويد. الإشعار يتيح إيقاف الحجب في أي وقت.
4. أغلق التطبيق الذي تظهر فيه الإعلانات وافتحه مجددًا. الإعلانات المحمّلة مسبقًا وذاكرة DNS السابقة قد لا تختفي فورًا.
5. من **القواعد**، حدّث القائمة عند الحاجة، اختر مزوّد DNS إذا كان مزوّدك الحالي بطيئًا أو محجوبًا، أو استثنِ تطبيقًا/نطاقًا إذا تعطل.

يعمل أيضًا على جهاز مروّت، بنفس وضع VPN المحلي، **ولا يطلب أو يستخدم الروت**. ليس فيه وضع تعديل ملف hosts.

## المزايا الفعلية

- VPN محلي لتصفية DNS فقط؛ بقية الاتصالات لا تمر عبر خادم VPN تابع للتطبيق.
- قائمة HaGeZi Multi LIGHT الافتراضية مضمّنة: **36,608 نطاقات** عند البناء، وخيار NORMAL أوسع: **191,639 نطاقًا**.
- يمنع النطاقات المطابقة وفروعها برد DNS من نوع NXDOMAIN قبل إرسالها للخارج، ويكشف الحجب عبر CNAME أيضًا.
- حلّ أسماء النطاقات المسموحة عبر DNS over HTTPS مع التحقق الافتراضي من شهادات TLS وأسماء الخوادم، من مزوّد تختاره.
- نطاقات مسموحة، حجب يدوي، قائمة إضافية من رابط، واستثناء تطبيقات ذات أيقونات تشغيل. السماح يتقدّم على الحجب.
- يدعم نقل DNS المحلي عبر UDP وTCP، وردود A وAAAA وغيرها من أنواع DNS القياسية ذات سؤال واحد.
- عند تجاوز الرد حجم UDP المناسب، يعيد إشارة TC، مع دعم إعادة المحاولة عبر TCP.
- ذاكرة DNS مؤقتة محدودة في RAM تحترم TTL، وتخزّن أيضًا الردود السلبية (NXDOMAIN) وفق TTL الخاص بسجل SOA، وتُمحى عند إيقاف الاتصال.
- عدادات فعلية لطلبات DNS والمحجوب منها؛ **ليست قياسًا لعدد الإعلانات المرئية التي أزيلت**. العدادات فقط محفوظة بين مرات فتح التطبيق.
- تحديث القائمة يدويًا عبر HTTPS، مع فحص الصيغة والحجم والحفاظ على النسخة السابقة عند الفشل.
- زر الاختصارات السريعة، ودعم Always-on الاختياري، وإشعار دائم بزر إيقاف.
- لا حسابات، ولا إعلانات داخل التطبيق، ولا SDK تحليلات أو تتبّع.

## حدود مهمة

- إعلانات يوتيوب، وإعلانات تأتي من نفس نطاق المحتوى، كثيرًا ما لا يمكن حجبها بهذه الطريقة.
- DNS الآمن الخاص داخل التطبيق أو المتصفح، وعناوين IP المباشرة، وDNS الخاص المضبوط على مزوّد محدد، قد تتجاوز الحجب.
- إذا لم يعمل الحجب، راجع إعداد **DNS الخاص** واجعله تلقائيًا أو إيقافًا. راجع كذلك إعداد DNS الآمن داخل المتصفح.
- بعض الألعاب تشترط مشاهدة إعلان للحصول على مكافأة؛ الحجب قد يمنع المكافأة أو يعطل جزءًا منها.
- قد تبقى مساحات فارغة بدل الإعلانات؛ التطبيق لا يعيد تصميم واجهات التطبيقات الأخرى.
- لا يعمل بالتزامن مع VPN آخر.
- **لا تفعّل «حظر الاتصالات بدون VPN»** مع صافي: هو ينقل DNS فقط، وهذا الخيار سيقطع بقية الاتصالات. التطبيق يعرض لك تنبيهًا إذا وجده مفعّلًا.
- «VPN دائم التشغيل» متاح من إعدادات أندرويد، وبعد تفعيله تستطيع تشغيل الحماية تلقائيًا بعد الإقلاع؛ التطبيق نفسه لا يبدأ من تلقاء نفسه.
- الحماية لا تزال تحتاج تشغيلًا يدويًا بعد إعادة التشغيل إن لم تفعّل Always-on.
- إذا كان مزوّد DNS المختار محجوبًا في شبكتك أو انقطع الإنترنت، قد تتوقف أسماء المواقع الجديدة عن العمل حتى يعود الاتصال أو تغيّر المزوّد. لا توجد عودة صامتة إلى DNS غير مشفّر.
- لا يوجد تفكيك TLS أو اعتراض HTTPS، ولا شهادة تثبتها على الهاتف، ولا صلاحية قراءة الرسائل أو الملفات.
- نقل DNS إلى الواجهة الافتراضية يستخدم IPv4، لكنه يدعم استعلامات IPv6/AAAA ويسمح باتصالات IPv6 العادية خارج النفق. حزم IP المجزأة والأسئلة المتعددة في رسالة DNS واحدة ليست مدعومة.
- القائمة الإضافية من رابط تتطلب صيغة نطاقات/hosts/`||domain^`؛ قواعد Adblock المتقدمة (مسارات، تعبيرات نمطية، استثناءات `@@`) غير مدعومة.

## الخصوصية والجهات الخارجية

- تُقرأ أسماء النطاقات في الذاكرة لإجراء المطابقة. بشكل افتراضي لا يوجد سجل أسماء محفوظ أو تحليلات.
- الفحص الاختياري، بعد موافقة منفصلة، يحتفظ بأسماء وقرارات DNS مؤقتًا في RAM فقط لمدة دقيقتين، وقد يشمل أي تطبيق مفتوح. لا يرفع التقرير تلقائيًا؛ مشاركته تتطلب نسخًا يدويًا ومراجعتك.
- سجل الأعطال المحلي يحفظ آخر الاستثناءات داخل التخزين الخاص بالتطبيق فقط، ولا يُرسل إلى أي جهة.
- النطاقات المسموحة تُرسل مشفّرة إلى مزوّد DNS الذي تختاره؛ يستطيع المزوّد رؤية تلك الطلبات وعنوان الاتصال. التطبيق ليس وسيلة إخفاء هوية.
- عند الضغط على **تحديث القائمة** أو تفعيل **قائمة إضافية** فقط، يتصل التطبيق بـ `raw.githubusercontent.com` أو بالرابط الذي أضفته أنت، بإعادة توجيهات https فقط.
- الإعدادات والقوائم والعدادات مخزّنة على الجهاز. النسخ الاحتياطي التلقائي للتطبيق معطّل (cloud backup ونقل الجهاز).
- روابط سياسات الخصوصية للمزوّدين موجودة داخل التطبيق: صفحة **حول ← سياسة خصوصية المزوّد الحالي**.

## البناء من المصدر

### Android Studio / Gradle

- JDK 17، Android SDK Platform 35، وBuild Tools 35.0.0.
- افتح هذا المجلد كمشروع Android Studio أو نفذ:

```bash
./gradlew :app:assembleDebug
```

الناتج في `app/build/outputs/apk/debug/app-debug.apk`. إصدار الإصدار النهائي (`assembleRelease`) يستخدم R8 مع `shrinkResources` وإبقاء أسماء الأصناف (لأن سجل الأعطال يعتمد على مقروئية آثار الاستدعاء). يوجد Gradle Wrapper مثبت الإصدار مع SHA-256 لتوزيعة Gradle.

### بناء خفيف دون Gradle — Linux

يتطلب JDK 11 أو أحدث (مع `javac` و`jar` و`keytool` في PATH)، وPython 3 وzip وSDK المذكور:

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
bash tools/build-apk.sh
```

الناتج: `artifacts/Safi-1.2.0.apk`. ينشئ السكربت مفتاح توقيع محليًا في `$HOME/.cache/safi-signing.jks` إن لم تحدد `SAFI_KEYSTORE`، بكلمة مرور تطوير افتراضية `android`. **لإصدار إنتاجي، استعمل مفتاحك وكلمة مرورك الخاصة، ولا تنشر المفتاح.** يمكن ضبط `SAFI_KEYSTORE`, `SAFI_KEY_PASS`, `SAFI_KEY_ALIAS`.

ملاحظة: هذا المسار لا يمرّ على R8، لذلك حجم APK الناتج منه أكبر قليلًا من ناتج Gradle. النتيجة الوظيفية واحدة.

مفتاح توقيع ملف APK المرفق غير مرفق بالمصدر. بناء نسخة بمفتاح مختلف يحتاج إزالة النسخة الحالية قبل التثبيت، ما يمسح إعداداتها. ملف APK للتثبيت المباشر وليس إصدارًا منشورًا على متجر Play.

## الاختبارات

```bash
bash tools/test-core.sh          # اختبارات محلية، بلا اتصال إنترنت
bash tools/test-core.sh --live   # يضيف استعلامات حقيقية إلى المزوّدين الثلاثة
```

- `CoreTests`: 64 تأكيدًا + 4000 مدخل DNS/IP تالف.
- `DiagnosticTests`: 31 تأكيدًا للخصوصية والتشخيص والملفات الشخصية.
- `HardeningTests`: 121 تأكيدًا لدمج الاستعلامات، قواطع الدائرة، الميزانية الزمنية، إبقاء الاتصال، الذاكرة السلبية، وصيغ القوائم.

تفاصيل الاختبارات وحدود التحقق الأصلية في `TESTING.md`، وإضافات هذا الإصدار في `tests/UPDATE-1.2.md`. الإصدار مشترك بين Gradle وسكربت البناء الخفيف عبر `app/version.properties`. لا يتضمن التطبيق أي شهادة أو استثناء TLS خاص ببيئة الاختبار.
